Drive Downloader

Mirrors a Google Drive folder onto your local disk, file by file.

Your browser blocked the popup. Allow popups for this site, then press Open Drive Downloader again.

Keep this tab open while the Disk Window is in use.

Before you start

  • Desktop Chrome only.
  • Keep this tab and the Disk Window both open until the Run ends: closing or reloading either one ends the Run, and closing this tab closes the Disk Window too.
  • Chrome won't let you choose your Downloads folder itself as the Target Folder: pick or create a sub-folder instead.
  • The first time you sign in you'll see Google's "unverified app" consent screen. That's expected for a script you deployed yourself; choose Advanced → Go to Drive Downloader (unsafe) to continue.

1. Paste a folder link and Read Drive

  • Paste a Drive folder link (My Drive, Shared with me, a public-by-link folder or a Shared Drive folder). A file link, or a folder you can't reach, shows an error under the field.
  • Press Read Drive. The left-hand Tree fills in with every Item below the Source Folder, fully expanded, with its size.

2. Choose a Local Target Folder

  • Press Local Target Folder and pick the Target Folder on your disk. The Source Folder is copied into it as a sub-folder of the same name, reusing one that's already there.
  • The right-hand tree fills in with what's already in the Target Folder, row by row beside the Drive Tree — see "Right-tree Results" below.
  • The chosen folder is remembered for next time; Chrome asks you to confirm permission again on each visit.

3. Adjust the options

  • Untick anything in the Tree you don't want copied.
  • Skip existing files — on by default, see below.
  • Replace spaces with underscores in Local Names.
  • Use Shortcut target names — names a Shortcut after what it points to instead of its own name.
  • Keep screen awake during download — see "Sleep" below.

4. Download

  • Files are copied one at a time. The status line shows the current file and its progress; the overall bar shows settled files and bytes transferred.
  • Pause freezes the current file; Resume carries on from the same byte. Stop ends the Run and leaves no half-written file.
  • When the Run ends you get a summary by Item Status. Pressing Download again starts a new Run with statuses reset — with "Skip existing files" on, it only fetches what's missing or failed.

Item Statuses

pending waiting its turn
downloading transferring now
done saved (or overwritten) on disk
exists already on disk, skipped (only with "Skip existing files")
failed gave up, with a reason (network, blocked by owner, flagged as abusive, a folder in the way)
unsupported a Google type that can't be exported (Forms, Sites, My Maps…)
loop a Shortcut back into its own ancestry, skipped
unselected you unticked it, skipped

Right-tree Results

The right-hand tree shows the Target Folder as it stands, each Drive Item beside the local item it becomes. Hatching marks a side with nothing there. A folder's Result is matched (already there, reused) or new folder; a local folder not in the Tree is local only. A file's Result is new, keep (already there, will be skipped), overwrite (pending, will be replaced), writing (in progress), then once the Run has touched it: saved, overwritten, kept (a failure or loop left an existing file untouched), not written (a failure or loop with nothing there to begin with), local only, untouched (you unticked it), or in the way (a local folder is sitting where a file needs to go).

Names and sizes

  • Spaces at the start or end of a name are dropped (a name of only spaces becomes +). Characters your disk can't use in a name become +. With "Replace spaces with underscores" on, the remaining spaces become _ too.
  • Same-named files or folders in a Drive folder (case is ignored) are numbered name (1).ext, name (2).ext… in sibling order, before the last extension; folders get the number at the end.
  • A Native File's size shows as ? until it's done, then its real size on disk. A folder or overall total shows a trailing + while any ? remains below it, meaning the total is a lower bound.

Skip versus overwrite

  • With Skip existing files checked (the default every time the Disk Window opens), a file already on disk with the same Local Name is marked exists and left alone.
  • Unchecked, existing files are overwritten instead, after one "N existing files will be overwritten. Continue?" confirmation. The old copy is only replaced once the new one finishes, so a failure, Stop or closed window never loses it.
  • Nothing on disk is ever deleted, apart from the partial new file a Stop leaves behind mid-transfer.

Shortcuts

  • A Shortcut (badge ↪) is mirrored as the file or folder it points at, not as a link.
  • By default it keeps its own name; with "Use Shortcut target names" on it takes its target's name instead, with the target's extension appended if that name doesn't already have it.
  • A Shortcut that points back into its own ancestry is marked loop and skipped, so reading never recurses forever.
  • A Shortcut whose target you can't reach is marked failed with a reason.

Native File exports

  • Google Docs, Sheets and Slides have no bytes of their own: they're exported to .docx, .xlsx and .pptx, with that extension appended unless the name already ends in it.
  • A Native File too big for Drive's normal export is still downloaded, just by a slower path.
  • Other Google types with nothing to export — Forms, Sites, My Maps, Vids and the like — are marked unsupported and left out.

Limits

  • Up to 1000 files per Source Folder. No limit on a single file's size.
  • Files are copied one at a time, never in parallel.
  • Reloading or closing either window ends the Run; there's no resuming mid-Run. Start a new Run with "Skip existing files" on to pick up where it left off.

Sleep

  • Keep screen awake during download is on by default and holds your screen awake for as long as a Run is running.
  • It can't stop your computer itself from sleeping: if you turn it off, set your computer not to sleep for the Run's duration instead.
  • Closing the lid stops a Run either way.
